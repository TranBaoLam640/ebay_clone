# Product seed images

Put product images for the catalog seed script in this folder.

Recommended:

- Use `.webp`, `.jpg`, `.jpeg`, or `.png`.
- Use lowercase filenames.
- Avoid spaces and Vietnamese accents.
- Use hyphens between words.

Examples:

```text
wireless-headphones-1.webp
gaming-laptop-1.webp
running-shoes-1.webp
leather-bag-1.webp
office-chair-1.webp
```
