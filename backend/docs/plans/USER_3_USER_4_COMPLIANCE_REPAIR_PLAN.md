## Scope and constraints

## Implementation sequence

1. Add direct schema/repository/provider unit tests that define the repaired contracts.
2. Repair Coupon, CouponUsage, Cart sync/DTO, and deterministic seed behavior.
3. Replace checkout idempotency with atomic claim/replay/failure semantics and exact response persistence.
4. Add atomic stock transitions, coupon-user counters, and exactly-once payment reversal.
5. Introduce the PayPal provider contract and safe Payment DTO/projections.
6. Complete Order query contracts and Return model/routes/transactions/notifications.
7. Add rollback-injection, concurrency, route-inventory, and regression tests.
8. Update User3/User4 API docs, architecture/context, and audits.
9. Target-format only files changed for this repair, run focused User3/User4 tests, then ESLint and targeted Prettier checks. Do not run seed, commit, or push.
